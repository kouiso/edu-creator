# 📸 Screenshot Integration Skill

## 目的

チュートリアルの理解を助ける、適切なスクリーンショットを配置し、視覚的な学習体験を提供する。

## 核心原則

### 1. スクリーンショットの役割

- 文章では伝わりにくい視覚情報を補完
- 初心者が「正しく動いているか」を確認するための基準
- エラー画面の特定を容易にする

### 2. 適切な配置タイミング

- **必須**: 操作結果が画面に表示される箇所
- **推奨**: 複雑なUI操作の説明
- **不要**: テキストだけで十分理解できる箇所

## ベストプラクティス

### ✅ やるべきこと

1. **alt_text（代替テキスト）を必ず記載**
   - スクリーンリーダー対応
   - 画像が表示されない環境への配慮
   
   ```json
   {
     "filename": "day01-step01.png",
     "alt_text": "ターミナルに「Hello World」と表示されている画面",
     "caption": "正常に実行されると、このように表示されます"
   }
   ```

2. **重要な部分を強調**
   - 赤枠や矢印で注目すべき箇所を明示
   - 初心者が「どこを見ればいいか」迷わないようにする

3. **実際の操作結果をキャプチャ**
   - 加工や編集を最小限に
   - 「実際にこうなる」という証拠を提示

4. **captionで文脈を説明**
   - 単なる説明の繰り返しではなく、補足情報を提供
   - 「何が正しい状態か」を明示

### ❌ 絶対禁止事項

1. **スクリーンショットを説明なしで挿入**
   - 必ずalt_textとcaptionを記載

2. **古いバージョンのスクリーンショット**
   - UIが変わっている場合は必ず最新版を使用

3. **機密情報を含むスクリーンショット**
   - APIキー、パスワード、個人情報は必ずマスク

4. **ぼやけた・小さすぎるスクリーンショット**
   - 読めないスクリーンショットは逆効果

## スクリーンショット命名規則

### ファイル名フォーマット

```
{章番号}-{ステップ番号}-{内容}.png

例:
- day01-step01-terminal-hello.png
- day02-step03-browser-result.png
- day05-step02-error-message.png
```

### 解像度・サイズ

- **推奨解像度**: 1920x1080以上
- **ファイルサイズ**: 500KB以下（圧縮推奨）
- **フォーマット**: PNG（UI）、JPG（写真）

## 配置場所の判断

### 必須配置

1. **最終成果物の確認**
   - 章の最後で「このようになります」を示す

2. **エラーメッセージ**
   - 「このエラーが出たら」の視覚的証拠

3. **初めて触るツールのUI**
   - 「どこをクリックするか」の指示

### 推奨配置

1. **複雑な設定画面**
   - 多くの入力項目がある場合

2. **デザインの変化**
   - CSSを適用する前後の比較

### 不要な配置

1. **コードを単に画像化しただけ**
   - コードブロックで十分

2. **文章で説明できる単純な操作**
   - 「保存ボタンをクリック」程度ならテキストのみでOK

## チェックリスト

スクリーンショット追加時の確認項目：

- [ ] filenameが命名規則に従っているか？
- [ ] alt_textが記載されているか？
- [ ] captionで文脈が説明されているか？
- [ ] 機密情報がマスクされているか？
- [ ] 解像度・サイズが適切か？
- [ ] 配置場所が適切か（必須/推奨に該当するか）？

## 実例

### 良い例

```json
{
  "filename": "day01-step02-terminal-create-next-app.png",
  "alt_text": "ターミナルで `npx create-next-app@latest` を実行し、プロジェクト名を入力している画面",
  "caption": "プロジェクト名に「my-app」と入力します。この後、TypeScript/Tailwind CSSを選択する画面が表示されます。"
}
```

### 悪い例

```json
{
  "filename": "screenshot1.png",
  "alt_text": "",
  "caption": ""
}
```

**問題点**
- filenameが不明瞭
- alt_textがない
- captionがない
