# お手本仕様書（床・天井・客観ルーブリック）

このファイルは、教材の本文（Step）を書く・書き直すときの合格の物差しを、機械と人が同じ基準で判定できるようにまとめたもの。
`SKILL.md` の思考の手順（6 つの手順・5 つの不在・なぜを教える）を実行したうえで、最後にこの物差しで合否を確かめる。

由来: 「AI 独特の言い回し・翻訳文感・完成品の配布・用語が噛み砕けていない」という教材の弱点を、
実際に読まれる教材の構造と比べて、下限（床）と、それを超えるべき点（天井）に言語化した。
定量の測定ではなく、読み比べから導いた定性の基準である。

## 床（最低ライン。全 Day で必須）

- 冒頭に、今日のゴールと完成イメージを先に出す（読者が地図を持ってから手を動かせる）
- 前日からの接続を 1 文置く（「Day N-1 の続きから」）
- 必要な前提・環境を明示する
- 1 ステップ 1 トピック。手順を飛ばさない（「同様に」「残りも」「以下略」の禁止）
- コードブロックは、依頼文の行数以下。1 行目に書き込み先を書く。分割するとコピーできなくなる完全な 1 ファイルだけ、
  `SKILL.md` の「コードブロックの長さの例外」を使う
- 表で列挙する（散文でだらだら並べない）
- 新出の専門用語は、初出の箇所で噛み砕く（読み方・役割・例え）
- 画面で確かめる所は、スクリーンショットで要所を見せる
- 文体（ですます体・AI 典型構文の禁止・偏愛語）は `SKILL.md` の規則に従う（一覧はここに再掲しない）

## 天井（床を超えるために必須）

「写経が中心でなぜが薄い」「完成品の配布に頼る」教材の弱点を、逆にする。

- **なぜこう動くか**を、各コードブロックの直後に必ず書く（手順書化の否定）
- **メンタルモデルを渡す**: 手続きの前にそれが解く問題を示し、既に知っている構造に結びつける
- **その日の学習対象は、読者が自分で書く導線にする**: 完成品を配って登録させるだけの日を作らない。
  周辺のコードを提供コードとして配る教材なら、売り文句もその実態（中心は自作、周辺は提供）に合わせて正直に書く
- **つまずきの対処**を用意する（その日のエラーと直し方）
- 淡々としすぎず、初心者への親しみを持つ（ただし AI 臭・方言は入れない）

## 客観ルーブリック（全部満たせば合格）

| # | 判定項目 | 判定手段 |
|---|---------|---------|
| 1 | 地の文に常体の混入がない（コード・コメント・アプリの表示文字列は除く） | 目視と `edu-creator check` の `tone` |
| 2 | 英語直訳調がない（「することが可能です」「これにより」「〜と言えるでしょう」「さまざまな」など） | 目視と検索 |
| 3 | 各コードブロックの直後に「なぜ」がある | 目視 |
| 4 | 新出の専門用語に初出の注釈がある（教材の中で未注釈の用語は 1 個でも失敗。前の Day で注釈済みの再出は警告） | `edu-creator check` の `comprehension` |
| 5 | 比喩・例え話は、直後に実体（コード・ファイル・動作）へ着地する。比喩で締めない | 目視 |
| 6 | スクリーンショットの参照が一意（同じ画像の重複がない）で、キャプションと画像が合っている | ファイルの中身の比較と目視 |
| 7 | Step ごとの検査と Day の全部の検査に通る | `edu-creator check` |
| 8 | 冷えた読み手（別のエージェントの初心者）が全範囲・全観点を確かめ、有効な指摘を全て直した。指摘 0 件も、確かめた根拠があれば有効 | `edu-creator judge run` |
| 9 | 冷えた読み手が、その日の追加課題（似た手続き）を本文の情報だけで再現できた | `edu-creator judge run` |

## 機械が見逃す層（検査に通ることは品質ではない）

- 常体の混入は、検査をすり抜ける形がある。目視で全数を見る
- 語り口と翻訳文感は、文章の検査の対象にならない。冷えた読み手で拾う
- スクリーンショットの重複・誤ったキャプションは、文章の検査の対象外。画像の中身の比較と目視で見る

**表面の指標だけで「完了」と報告しない。** 合格に届いた・最初の通しだけ・未着手を、本当の状態で報告する。

**販売の判定の最終の物差しは、自己採点の外に置く。** ルーブリックを書いた本人（同系の AI）が採点しても、独立した品質保証にならない。
別の会話の冷えた読み手が、教材の本文だけを頼りに通しで再現する確かめを、判定の記録として残す。
実際の初心者による観察テストを行っていない場合は、未実施と明記し、人間の理解度を実証したとは報告しない。
