# 絶対禁止事項（edu-creator）

## Plan Modeでの自己レビュー義務

自己レビューが全チェック項目で100/100に達していない状態で、ExitPlanModeを呼んだり計画をユーザーに提示したりすることを禁止する。理由：未完成の計画を提示すると品質保証の負担がユーザー側に移り、既知の欠陥にユーザーのレビュー時間を浪費させてしまうため。

```
❌ 自己レビュー: 85/100 → 「このプランで進めてええかな？」（ユーザーが品質チェッカーにされてしまう）
❌ 自己レビュー: 92/100 → ExitPlanMode（既知の問題をそのままユーザーへ渡してしまう）

✅ 自己レビュー: 85/100 → 全問題を修正 → 再レビュー → 95/100 → 残りを修正 → 100/100 → ExitPlanMode
```

**自己レビューチェックリスト**（ExitPlanMode前の最低条件）：
1. 計画ファイル全体を読み直す
2. 各編集を実際のファイル内容と突き合わせる（正確な行番号・正確な文字列で）
3. 波及影響を確認する（例：件数を変更すると複数箇所に影響が及ぶ）
4. 既存ファイルの規約とフォーマットの一貫性を確認する
5. 更新すべきなのに古いままの参照をgrepで探す
6. 新規ファイルの内容が（見出しだけでなく）完全に書かれているか確認する

**確信度**: High
